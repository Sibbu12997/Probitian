# ProBitian — Learn Data. Build Skills. Grow Your Career.

> **ProBitian** is a modern, high-performance learning platform focused on Data Analytics, Power BI, SQL, Excel, AI and Career Growth.

## 🚀 Key Features

1. **Practical Learning Modules**: Industry-focused courses covering Power BI, SQL, Excel, Power Query, DAX, AI Tools, and Career Guidance.
2. **Interactive Project Showcases**: Real-world BI dashboards including CRM, Sales, HR, Finance, Marketing, and Inventory Dashboards.
3. **Blog & YouTube Content Hub**: Modern, searchable blog listing with categories and video tutorials.
4. **Interactive Contact Experience**: Contact form, embedded map locator, direct email, and social connections.
5. **SEO & Performance Optimized**: Complete with `sitemap.xml`, `robots.txt`, OpenGraph metadata, JSON-LD structured data, and high contrast legibility.
6. **Dark & Light Mode Support**: Smooth theme toggle respecting user preferences.
7. **Vercel Ready**: Includes `vercel.json` and `next.config.ts` for instant deployment.

## 🛠 Tech Stack

- **Framework**: React 19 / Vite / Next.js ready
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Language**: TypeScript

---

## 💻 Local Development Setup

```bash
# Clone the repository
git clone https://github.com/probitian/probitian-website.git

# Navigate into the folder
cd probitian-website

# Install dependencies
npm install

# Run dev server
npm run dev
```

Open `http://localhost:3000` in your browser.

---

## 🚀 Vercel Deployment

Simply push to GitHub and import into Vercel, or run:

```bash
vercel --prod
```
